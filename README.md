# atlas-tanstack-react-start-quickstart

A minimal TanStack Start app pre-wired with [Atlas](https://atlasauth.net) auth,
using `@atlasauth/tanstack-react-start`.

The package re-exports the full `@atlasauth/react` surface, so the client
components (`<AtlasProvider>`, `<SignIn>`, `<SignedIn>`, `<UserButton>`,
`useUser`) and the server helper (`fetchAtlasAuth`) all come from this one
package.

## What it shows

- `src/routes/__root.tsx` — `<AtlasProvider>` mounted at the root, with a
  `<SignedIn>` / `<SignedOut>` + `<UserButton>` header.
- `src/routes/index.tsx` — a public home page using `useUser()`.
- `src/routes/sign-in.tsx` — the `<SignIn>` flow.
- `src/auth.ts` — a `createServerFn` that verifies the session via
  `fetchAtlasAuth(getWebRequest)`.
- `src/routes/dashboard.tsx` — a protected route whose `beforeLoad` calls that
  server function and redirects signed-out visitors to `/sign-in`.

> `src/routeTree.gen.ts` is generated by the TanStack Router Vite plugin the
> first time you run `npm run dev` (it is gitignored).

## Run it

1. `npm install`
2. `cp .env.example .env`, then set `VITE_ATLAS_PUBLISHABLE_KEY`,
   `VITE_ATLAS_FRONTEND_API`, `ATLAS_JWKS_URL`, and `ATLAS_ISSUER` to the values
   from [atlasauth.net](https://atlasauth.net).
3. `npm run dev`

Open http://localhost:3000. Visit `/dashboard` to see server-verified protection.
